# Re-Union X brand

Proposal **A, «Reunion ring»** (chosen by the project owner, 10 Nov 2026): five ring segments (the Unions coming back
together) around an interlaced X, with an orange spark. Drawn from scratch: no Square Enix / Disney marks (no crown,
heart, keyblade or «χ» glyph).

| File | Use |
|---|---|
| `emblem.svg` | the emblem on a navy disc (site header, any size from 32 px up) |
| `icon-square.svg`, `icon-1024.png` | square app/bot icon (Discord bot avatar; Discord crops it to a circle, the drawing stays inside) |
| `favicon.svg` | simplified emblem for 16-32 px (browser tab) |
| `apple-touch-icon.png` | 180 px home-screen icon |
| `og.png` | 1200x630 link preview (Discord, social networks) |

Colours (same as the site): navy `#06182b` / `#0a2f55`, blue `#0b4f8f`, edge `#1d8fe0`, cyan `#5fe0f0`,
spark orange `#ffae3b`, text `#eef4f7`, muted `#9fc3d6`. Wordmark font in the link preview: Chakra Petch 700
(Google Fonts, OFL); the site keeps M PLUS Rounded 1c for its headings.
