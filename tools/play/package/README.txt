RE-UNION X - TEST PACKAGE
=========================

Re-Union X is an unofficial, non-commercial fan restoration of Kingdom Hearts Union X[Cross].
It is not affiliated with, endorsed or sponsored by Square Enix or Disney.

This package is private and personal. Please do not share it or any file inside it.


HOW TO PLAY
-----------
1. Put this folder somewhere with at least 20 GB free, for example D:\Games\Re-Union X.
   Do NOT put it inside OneDrive (Documents and Desktop are often synced to OneDrive).
2. Double-click "Play".
   - If LDPlayer 9.5.37 is not installed, Play offers to install it from this folder.
     Re-Union X only works with this exact LDPlayer version: keep LDPlayer's updates off.
   - The first start takes a few minutes. A window shows what is happening.
3. When the game shows its title screen, tap KHUX START.
   The first time the game downloads about 4 GB of data: tap Download and keep the game
   open until it finishes.

ALWAYS START THE GAME WITH "Play".
Opening LDPlayer or the game from their own icons shows "End of Service": close LDPlayer
and use Play.

Your save is kept in %LOCALAPPDATA%\Re-Union X\save (it survives package updates).
To update, unpack the new package and use its Play.


WHAT YOU CAN DO
---------------
The save starts with every story quest (1-979) and every Proud quest cleared, the whole
Medal List and the strongest medals, so you can try every feature restored so far:
story and Proud quests, Medal List, Level Up, Evolve, Moogle Shop, Shop, Missions,
Avatar Boards, Spirit. Union Cross, raids, Coliseum, PvP and events do not exist yet.
Every difference from the original game is explained in the in-game Notices.


SOMETHING WENT WRONG?
---------------------
The game is a work in progress: bugs and crashes are expected. Please report them on the
Re-Union X Discord (#bug-reports) with:
- what you were doing and what happened (a screenshot or short video helps);
- the files in %LOCALAPPDATA%\Re-Union X\logs: play.log, server.log and server.prev.log
  (server.prev.log is the game session before the last start of Play: send it after a crash).

If Play shows an error, it tells you what to do and which log file to send.
